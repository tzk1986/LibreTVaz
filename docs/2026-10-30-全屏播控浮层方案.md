# 全屏播控浮层方案（详情页全屏时的上/下集与快进快退）

> 状态：**方案待确认**（确认后实施，单 commit 可 revert）
> 提出背景（2026-10-30 用户验收）：手机经局域网访问模拟页，视频全屏后画面上没有任何按钮——现状全屏是**原生 `<video>` 元素全屏**，浏览器只给自带控件；页面里的「« 上一集 / 下一集 »」在全屏时不可见，且全屏内 ↑↓ 无换集键位 → 电视/手机场景全屏中完全无法换集。用户定调：走完整做法（自绘浮层），需要考虑遥控；**首集时「上集」置灰、末集时「下集」置灰**（不隐藏）。

## 一、同类项目调研

| 项目 | 全屏形态 | 上/下集 | 显隐/键位模型 | 对本方案的启示 |
|---|---|---|---|---|
| **主站 LibreTV（同仓库 src/components/player-shell.tsx:537-558）** | ArtPlayer：容器全屏 + HTML 控制条（全屏时仍在） | 自定义 `prev-episode`/`next-episode` 按钮放播放键右侧（"换集是最高频动作，不该滚回页面找按钮"），`Alt+←/→` 快捷键 | `art.controls.show` 空闲自动隐藏、按键/鼠标唤回（L845-854） | **首选参照**：交互意图与页面按钮 disabled 规则（watch/page.tsx:366,373 `currentIndex<=0` / `>=length-1` 置灰）直接照搬 |
| **FongMi TV leanback（app/src/leanback/res/layout/view_control_vod*.xml）** | 播放器 Surface + 自绘控制层（seek 条 + action 行） | action 行含 **`prev`/`next`（换集）** + parse 换线、speed 倍速、text 字幕、opening/ending 跳片头等 | 任意按键唤出控制层，无操作数秒自动隐藏；Back 分层（层开→收层，层关→退出） | 控制层元素优先级清单；「按键即唤回、闲置自动收起」是 TV 标准 |
| **Android TV 官方规范（developer.android.com/training/tv/playback/controls）** | — | MediaSession NEXT/PREVIOUS 为推荐动作 | 方向中键=暂停+显示叠加层；任意键重置隐藏计时 | Esc 原生退全屏=系统层，我们键位不与浏览器抢 |
| **Video.js / Plyr（通用 web 播放器范式）** | `player` 容器 requestFullscreen，控制条是容器内 HTML → 全屏内可见 | 可注入自定义按钮（无内建换集） | inactive 超时淡出，pointer/key 活动重置 | 证实「div 全屏 + 覆盖层」是 web 通用做法，非 hack |

**web 端硬约束**：iOS Safari/微信只允许 `<video>` 原生全屏（`webkitEnterFullscreen`），div 全屏 API 缺失 → 浮层做不出来，只能回退原生控件（无换集按钮）。Android Chrome、桌面 Chrome/Edge、TV 浏览器均支持元素全屏。方案按「能力检测 + 双路径」设计。

## 二、设计

### 1. 结构与显隐
- fongmi.html 新增 `#fsStage`（非全屏 `display:none`；`:fullscreen` 时 100vw/100vh 黑底）内含 `<video>`（运行时从页面移入，退全屏移回原位）+ 底部 `#fsBar` 浮层：
  `⏮ 上一集 · ⏯ 播放/暂停 · 下一集 ⏭ · {片名 线路·第N集/共M集} · ⛶ 退出全屏(Esc)`
- 焦点引擎 scope：`document.fullscreenElement===#fsStage` 时 items 限定 `#fsStage`（画面 video 本就 `data-focus`），↑↓ 在画面↔按钮行间移动，←→ 在按钮行内移动；焦点在画面上 ←→ 仍是 ±15s seek（沿用 L326 现有逻辑，toast 带 mm:ss/总长）。
- 自动隐藏：进入全屏及每次按键/点击后 `#fsBar` 显示，5s 无操作淡出（CSS opacity 过渡，`pointer-events:none` 同步）；任意按键立即唤回——对齐 FongMi/ArtPlayer。遥控场景实体键（含音量通道键到达不了 web，忽略）与触屏点击均触发唤回。

### 2. 上/下集边界置灰（用户明确要求）
- `syncFsBar()` 在每次 `draw(ep)`、goEp、换线、进入全屏时刷新：
  - `curEp <= 0` → 「⏮ 上一集」加 `.off`；`curEp >= total-1` → 「下一集 ⏭」加 `.off`；total≤1（电影单集）→ 两个都置灰（保留显示，不隐藏）。
  - `.off` 可聚焦、点击只 toast「已是第一集 / 已是最后一集」，不切集（与页面按钮行为一致）。
  - 中部信息区实时显示 `第N集/共M集 + 本集名`，让用户知道边界状态。
- **页面级按钮同步置灰**：详情页 hrow 里现有 `#prevEp/#nextEp` 用同一规则加 `.off`（对齐主站 disabled），`.btn.off{opacity:.4}` 样式补充（现仅有 `.chip.off`）。

### 3. 换集行为
- 浮层按钮复用 openDetail 现有 `goEp(±1)`（含 tried 重置、draw 高亮、playInto 起播、`fongmi_autonext` 连播链路零改动）。经模块级钩子 `fsCtl={go, state}` 由 openDetail 注入；离开视频视图（switchView）置 null。
- 播完自动连播发生时 `draw(curEp)`→`syncFsBar()`，全屏内进度条与集号信息同步更新。

### 4. 直播全屏
- `fsCtl=null` → 上/下集按钮隐藏（直播无集概念），保留 ⏯/⛶；信息区显示当前频道名。
- 现有直播键位劫持在全屏时已放行（L294 `!document.fullscreenElement` 守卫），不回归。

### 5. 兼容回退
- `toggleFullscreen()`：优先 `#fsStage.requestFullscreen()`（成功则移入 video，失败回滚原位置）；无元素全屏 API（iOS）→ 回退 `video.webkitEnterFullscreen?/requestFullscreen`（原生控件，无换集浮层），toast 提示「当前浏览器全屏不支持自定义控件」。
- 全屏中切视图/返回：`switchView` 里若 fsStage 处于全屏先 `exitFullscreen()`，video 归位后再重绘，防孤儿。
- 退全屏（Esc/按钮/切页）统一在 `fullscreenchange` 里把 video 移回原父节点并更新 fsBtn/liveFs 文案（现有逻辑扩展）。

风险：video 跨父节点迁移会触发一次重加载（src 不变时 Chrome 保流，实测若有闪断则在移入后 `play()` 恢复 currentTime）；iOS 用户无浮层属平台限制，明示降级。

## 四、验证
1. 手机局域网打开 → 详情页全屏 → 浮层出现，⏮/ 可点可焦；第 1 集时 ⏮ 灰（点击仅提示）；播到末集 ⏭ 灰。
2. 遥控/键盘：↑↓ 画面↔按钮、OK 触发、画面焦点下 ←→ seek toast；5s 无操作浮层淡出，任意键唤回；Esc 退全屏画面回原位不黑屏、播放不中断。
3. 连播：末集前 one 集等播完 → 自动进下集，全屏内集号+1、海报页选集高亮同步。
4. 直播全屏：无换集按钮、⏯/⛶ 正常；退出全屏直播继续。
5. `node test/run.mjs` 四套回归（无关联改动应全绿）。
