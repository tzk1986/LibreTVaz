## Phase A：debug-web（先行验证）

### A1 播放页线路并行测速（核心）
- **perf-core.js 新增纯函数**（双端复用，进 PerfCore 导出）：
  - `lineSpeedTag(kbps)` → `{label:'9.0MB/s 流畅'|'702KB/s 可能卡顿'|'慢/不可用', cls}`；阈值：≥1500KB/s 流畅(绿)、150~1500 可能卡顿(黄)、<150 或失败 慢/不可用(红)。**阈值是初标，可改**。
  - `pickBestLine(episodes, speedMap)` → 排除「不可用」，取测得最快且含流后缀的线；无线有速度时退回现状（首个流后缀线）。
- **fongmi.js 新增 `speedTestLines(d, curEp)`**：对 `d.episodes` 前 10 条线并行（pMap 并发 4），各取 `list[curEp||0].link`：
  - 非 m3u8 → `/proxy?url=` + `Range: bytes=0-131071`，fetch reader 累计字节、2.5s 预算 abort，KB/s = bytes×1000/ms；
  - m3u8 → 先过 /proxy 拉清单（分片地址已被改写为绝对），取首个分片做同法采样（更贴近真实带宽）；
  - 结果存**内存 Map**（key=detail 缓存键+集号，换集重测；不落 localStorage——线路随作品失效快）。
  - 时序：`paint()` 渲染后异步启动，完成一线刷一线（不阻塞首帧起播；起播仍用现默认选线）。
- **UI**：`#flagRow` 按钮文本改 `flag(N集) [9.0MB/s 流畅]`（绿/黄/红着色，复用 .on/.off 色系）；全部测完后若最快线≠当前且用户未手动换线 → 自动跳 `pickBestLine` 并 toast「已切换到最快线路」（开关 `fongmi_autobestline` 默认开，设置页可关）。
- 失败/超时线路标红「不可用」；`nextLine` 自动换线顺序同样吃 speedMap（不可用线排最后）。

## 已定决策（可推翻，请在本文档批注）
- 测速走 /proxy 同源（避 CORS）；m3u8 采样首个分片而非清单本身；每作品每集测一次、只存内存；最多测前 10 条线；阈值 1.5MB/s、150KB/s 两刀三档；「测速后自动跳最快线」默认开。
- 影视仓专属项（壁纸/DNS/迅雷缓存/EXO 缓存/播放器/解码/渲染/画面缩放/弹幕等）完全不做，连展示占位也不加（用户 2026-11-02 批注）。
- 设置页只呈现有真实行为的项；现有可用点播源清单另见 `docs/2026-11-02-现有可用点播源清单.md`。
- benzke9 APK 不反编译、不集成其代码，仅对标行为重实现。
- 预设 URL 用 raw.githubusercontent 直链为主（走 /proxy），gh-proxy 作自动备选。

## web 定稿增补记录（2026-11-02 下午，Phase B 移植以此为准）

### 1. 首页模型（P8/P9）
- **点播即 App 首页**：无独立首页视图（原功能行+更新推荐墙删除）；VodActivity 顶部导航栏 = getTabs()（点播自身不入栏、旧存档 vod 项读取时滤掉；刷新钮固定栏首=直播之前），项样式 .func（计数：收藏 N 部·更新 / 历史 N 部）。
- 「更新推荐」等效入口=单源模式首 chip「🏠 最新」（无分类全量最新）；`rec:` 缓存分片停生产。
- 设置项「首页Tab」更名「导航栏」（键 fongmi_tabs 不变）；各视图返回钮「← 点播」；Esc/播放返回/直播面板全部落点播。

### 2. Back/Esc 分层统一链（P2，backLayer）
- 单一函数分层：关换源弹窗 → 退全屏 → 退编辑（选中框保留）→ 收筛选行 → onEsc 链（ask/cfg/qr/src/find 弹窗 → 直播面板 → video→videoBack → collect→来源 → 资源口子页→资源口 → 其余→点播）→ 点播首页=回顶+焦点进分类行。
- 接管实现：加载时 `history.pushState` 挂一层捕获历史；浏览器后退/手机手势/部分 TV WebView 的 Back 经 popstate 汇入 backLayer 并立即重挂捕获层——首页 Back 不会退出页面；键盘 Esc 同走 backLayer。
- 安卓映射（Phase B 对照项）：APK 原生 Back 由系统分发，各 Activity onBackPressed 按同一分层序（IME→Dialog→Fragment→页面），点播首页双击退 App。
