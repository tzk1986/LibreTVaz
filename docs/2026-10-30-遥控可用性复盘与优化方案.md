## 一、同类电视项目交互调研（并入定调依据）

| 项目 | 焦点/输入模型 | 与本次定调的关系 |
|---|---|---|
| **Android TV / Leanback**（FongMi、TVBox 底座） | DPAD 四方向只移动焦点高亮；EditText 获焦点**不等于**弹键盘，OK(Select) 显式 showSoftInput；**Back 先收键盘、焦点留在原字段**，再按才导航返回 | 与用户描述逐条吻合，即行业标准模型；APK 端原生就是此行为，web 对齐后映射零成本 |
| **Kodi** | 焦点控件 + OK 弹全屏 OSK 对话框；Back=Close 只关键盘，**关闭弹窗焦点必须回到打开它的控件**（"Closing a dialog must return focus to its opener"，WAI-ARIA 同款）；Back/键盘层序处理不当的 bug（xbmc #29975）表现为下一次输入直接退出程序 | 弹窗（findModal/askModal）关闭后恢复焦点到触控件，是我们该抄的细节 |
| **Jellyfin Android TV** | 反面教材在案：#5300「按 Back 后焦点卡在搜索框出不去」、#5824「播放器按钮够不到」——皆因焦点逃逸路径未显式声明 | 我们几何评分移动+无死键兜底必须全站检查，见问题清单 |
| **Samsung Tizen TV** | 官方文档明示：IME 由遥控 Back 键或键盘 Done 键关闭 | Esc=退编辑优先于退页面，写进按键路由 |
| **react-native-tvos / android_tv_text_field** | 共性坑：键盘收起后 D-pad 卡在字段里，需原生包装恢复方向控制 | 退编辑后必须把方向键交还焦点引擎（R1） |
| **TVBox / FongMi 分类筛选**（用户指定复用调研） | 站点 json 自带 `class[].filter`/子类定义；TypeActivity 进入分类后 OK/菜单唤起 FilterDialog，选中项拼进 `ac=videolist` 的 URL 参数（`&area=美国&year=2023`），由**站点 API 自己实现过滤** | **交互形态 100% 复用**（进分类→二次OK弹筛选→选中即应用→返回焦点回分类）；**数据契约不可复用**——实测我们的采集站大多不带 filter 字段、`&area=` 类扩展参数无生效证据（hhzy t=2 仅 1 条无从验证，保守不依赖），故数据层用自研「分类中间件」替代（R8） |

**调研四原则（作为修复验收标准）**：
1. 选中 ≠ 编辑：焦点框（.focus）与浏览器 activeElement 分离，输入框只有按 OK 才 `.focus()` 进编辑态；
2. Back/Esc 分层消费：退编辑 → 关弹窗 → 返回上一页，一层一次按键；
3. 弹窗关闭焦点回到打开它的控件；
4. 任何选中态下四个方向至少有一条可达路径（无死键、无陷阱）。

## 三、修复方案

### R1 两段式输入（F1/F8，核心）
- Focus 引擎旁新增编辑态原语：`enterEdit(el)`（el.focus() + 加 `.editing` 高亮描边）、`exitEdit()`（activeElement.blur()，Focus.el 保留在该输入框）；`Focus.set` 对 input **只加选中框不给 DOM 焦点**。
- keydown 路由改造：
  - `Esc`：编辑态 → 退编辑（消费，不再 onEsc）；否则原 onEsc 链（弹窗→视图）——三层语义对齐 Android/Samsung Back。
  - `Enter`：`Focus.el` 是 INPUT/TEXTAREA → enterEdit；是 VIDEO → 播放/暂停切换；否则维持 `click()`。
  - 方向键：编辑态完全放行原生（光标/选区）；选中态（含 input 选中）统一 `Focus.move`。
- 删除三处自动 `focus()`：renderSearch 改 `Focus.set($('#kw'))`、drawSrcMgr 改 `Focus.set($('#smAdd'))`（订阅页语义=先看见操作区）、openFindBox 改 `Focus.set(kw)`（不再 select）。删 kw 上 ArrowDown→qrBtn 特例（两段式下几何移动天然可达，且编辑态方向键应归光标）。
- 编辑态样式：`.editing` 输入框 accent 边框 + 光标闪烁可见（区分"选中/正在输入"）。
- 远程推送不受影响：onSearch 直接写 value 并执行，不进编辑态。
- L919 subRow 改 Focus.set。

### R2 卡片删除可达（F2）
- `cardHtml` 的 `.del` 加 `data-focus`；卡片获焦时 `.del` 由 CSS 显形 → 自动进焦点候选；再按↑（或←）即选中 ×，OK 删除。补 `.del.focus` 白框样式。
- bindGrid 委托已兼容（click 冒泡命中 `[data-del]`）；删除重渲后把焦点还给网格首个卡片（无卡片则返回按钮），避免 F7 式漂移。
- 更正两处提示文案：「选中卡片后按 ↑ 再确定可删/取消收藏」。

### R3 findModal 入 scope + R4 页内确认框（F3/F4）
- `Focus.items()` scope 链插入 `#findModal`（优先级 qrModal > findModal > siteModal > srcModal > #app）；closeFindModal 已有"焦点回 player"保持。
- fongmi.html 新增 `#askModal`（消息 + 「确定/取消」两 data-focus 按钮，默认焦点=取消防误删，Esc=取消，点遮罩=取消）；JS `askYes(msg, onOk)`；替换 histClear / smClear / remoteLoop sub 确认三处 `confirm()`。

### R5 播放器焦点化（F5c/F6a/F6b）
- 两处 `<video>` 加 `data-focus`（进焦点环）。
- 全局 keydown：`Focus.el` 为 VIDEO 时——`Space`/`Enter`=播放/暂停 toggle（preventDefault，杜绝 Space 滚页）；详情页（非 live 面板关）`←/→`=`±15s seek` + toast「«15s / 15s»」；live 维持现有 ↑↓换台/←→开面板语义不变。
- `Enter` 分支跳过 VIDEO 的原 `click()`（无效动作）。

### R6 直播收藏星 + 返回可达（F5a/F5b）
- 面板关时 `←`/`→`= `togglePanel(true)`（替代 toast「仅 1 条线路」；开面板后方向键归焦点环，liveBack 面板顶部可达）。
- `drawPanel` 在 colChan 顶部插 `<div class="li"><button class="btn" data-focus id="favCur">☆ 收藏选中频道</button></div>`；点击对当前**焦点所在频道行**的 `data-i` 调 `toggleLiveFav`（焦点不在频道行则回落 `Live.cur` 正在播出频道）；按钮文案随收藏态变 ★/☆。

### R7 每视图初始焦点（F7）
- 约定各 render 末尾 `Focus.set` 主区首焦点：home→funcs「点播」；vod→typeRow 首 chip（未出则 vodBack）；search→kw（仅选中）；collect→cTabs「全部」；keep/hist→网格首卡（空则返回钮）；probe→probeGo；live/video→player（已有）；siteModal→网格首项（已有）；srcModal→smAdd；findModal→findKw。
- `switchView` 统一兜底：若 Focus.el 已脱离文档则不处理（各 render 自行设定）。

### R8 海报墙地区分类筛选（F9；交互 100% 复用 TVBox TypeActivity，数据层自研「分类中间件」）

**遥控交互流（对齐用户定调，改两处现行行为）**：
- 焦点在分类 chip（电影/电视剧/综艺）：OK#1=进入分类（现行不变）；**停留当前分类 chip 再按 OK#2=展开筛选行且 `Focus.set` 首个筛选项**（现 L916-921 已有二次点展开逻辑，把原生 `.focus()` 改 Focus.set 并入 R1）。
- 焦点在筛选行按 **Esc=焦点回该分类 chip，筛选行保持展开**；再按 OK=收起（恢复纯浏览）。
- 选中筛选项=**立即在当前分类应用、行不收起**（现行 drawSubRow 选中即 `showFilters=false` 收起，按用户流程改掉，方便连改）；每行首项「全部」或同项再按 OK=取消筛选回全量。
- 聚合墙模式本轮不加筛选。

**筛选预设（用户原话定义）**：

| 分类 | 预设 | 归类语义（用户 2026-10-30 定稿：港台属中国算国内；美国统一归欧美） |
|---|---|---|
| 电影 | 全部/国内/国外/日影/韩影/欧美 | 国内=大陆+港澳台；国外=除国内外全部（含欧美/日/韩/其它） |
| 电视剧 | 全部/国内/欧美剧/日剧/韩剧/小语种(其它) | 小语种=非国内、非欧美、非日、非韩（含东南亚、其它欧洲单国等） |
| 综艺 | 全部/国内/国外/日本/韩国 | 国外=非国内 |

**数据三级解析（按可靠度降序逐级回退）**：
- **(a) 源原生服务端筛选**：预设名→源分类树中**地区编码的类型 id**（全树 name 匹配，含 hhzy 型扁平 tops：欧美剧3/香港剧4/韩剧5/日剧6/内地剧20/台湾剧28/大陆综艺30/日韩综艺31/港台综艺32/欧美综艺33）。单 id→`t=` 直拉；多 id（国外=并集）→沿用 `loadMerged` L1052 并行合并去重。命中即最快最准，优先走此路。
- **(b) 客户端分类中间件（主兜底，用户定调的「中间模块」）**：`PerfCore.classifyVod(item)` 纯函数为每条目判地区，**信号优先级**：叶子 `type_name`（type_id 对应名）> `vod_area` 归一表 > `type`/`vod_class` 分词。地区枚举定稿：**DOM / EUUS / JP / KR / OTHER / UNKNOWN**（港澳台属中国归 DOM，美国统一归 EUUS）。归一表：`大陆/中国/国产/港/澳/台→DOM`；`美国/欧美/欧洲→EUUS`；`日本→JP`；`韩国→KR`；其余可辨地区（泰/英/法/德/印/东南亚等）→`OTHER`；无信号→`UNKNOWN`（**保守剔除并计数**，宁缺勿误，落实「不纯按关键字」）。渲染期过滤+滚动**续拉补页**（上限约 10 页），行尾提示「已拉 P 页 / 筛出 N 部」。关键字仅用于**词条→标签归一**，不做源类型名模糊映射。
- **(c) 皆不可**：源既无匹配 id、条目又全 UNKNOWN → 该预设 chip 置灰，OK toast「该源不支持此筛选」。

**实测依据附录（决策留档）**：hhzy `ac=list` 48 扁平 tops 无 subs（(a) 可用）；ffzy `ac=list` 经 /proxy 恒截断 1636B 拿不到 class，但 videolist 条目自带 `type_id` 叶子+`type_id_1` 父组（15韩国剧/16欧美剧/26港台综艺）+`vod_area`（(b) 可用）；hhzy t=2 仅 1 条，`&area=美国` 带/不带结果相同→不可判别，保守不依赖 API 扩展参数。
