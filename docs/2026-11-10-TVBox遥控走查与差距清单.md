# TVBox 全程遥控走查 × LibreTVaz 差距清单（2026-11-10）

## 一、走查方法与范围

- 蓝本：TVBox tk 版（`com.github.tvbox.osc.tk`，armeabi 包在 arm64 模拟器转译运行），本机已配好数据源。
- 环境：pixel7_api36 模拟器（emulator-5554，横屏 2400×1080），与 LibreTVaz 验证同机同分辨率。
- **全程遥控器模式**：只用 `adb shell input keyevent`（19/20/21/22=方向，66=OK，4=返回，82=MENU），不使用 touch tap；每步按键序列与 `screencap` 截图在同一条命令内连发（防控件 5s 自隐与转译 ANR 时序错位）。
- 证据：截图与 uiautomator dump 在 `D:/tangzk/tmp/`（文件名 `tv_*.png/.xml/_txt`，下文按屏引用）；全屏底栏控件以 dump 出的 resource-id 序列为准（`tv_fs3_ids.txt`、`tv_fs2_labels.txt`）。
- 覆盖屏：首页 / 分类 / 详情 / 全屏（顶栏+底栏+右侧时钟）/ 搜索 / 历史 / 设置全集（含数据源选择、备份还原两个子页）/ 存储空间 / 直播 / MENU 键。
- 局限：ARM 转译下 TVBox 高频卡顿，个别路径（播放器设置内部参数页）两次未达，标注「未走查」；直播未配置源，仅记录入口行为。

## 二、TVBox 逐屏实录要点

### 2.1 首页（tv_home / tv_h2 / tv_nav）
- 左上角「影视 | 电影天堂」标题 pill 本身就是**数据源快速切换入口**（OK 直达数据源选择页）。
- 顶栏右图标序：信号条（全网测速入口）→ `<>`（设置/备用入口）→ ▦（存储空间）→ ⚙（设置）→ 时钟（11月10日|周二 06:43，含星期）。
- 分类 chip 行：首页/电影片/连续剧/综艺片/动漫片/动作片/喜剧片/爱情片…（源自带 t分类）。
- 功能图标行：历史 / 直播 / 搜索 / 收藏 / 推送 / 文件。
- 焦点样式：红底+白描边（与我方 TvColors 方案一致）。

### 2.2 分类页（tv_cat）
- 空态=占位图标+「没找到数据」两行居中文案。

### 2.3 点播详情页（tv_detail / tv_menu_txt）
- **进入即自动起播预览**（小窗）；窗口内显「正在获取播放信息」，右上「0.00 Mbps」+loading 圈，底部有 mini OSD 细进度（红点+细线）。
- 右列信息：片名 | 影视 | 电影天堂 | 年份/地区/语言/类型 | 演员 | 简介。
- 按钮行实测：**[快搜] [倒序] [测速] [推送] [简介] [☆ 收藏]**。
- 线路 chip 进入即显「检测中」；选集多时用分页 tabs（1-100 / 101-200 / … 586 集实测分 6 页）。

### 2.4 全屏播放（tv_fs1 / tv_fs2 / tv_fs3）
- 顶栏：红竖条+标题（次行「1280 x 720」分辨率）+右上码率「0.61 Mbps」+loading（我方已复刻一致）。
- **底栏控件实测（resource-id 序列）**：
  ⏮ | play_pauseImg | ⏭ | play_speed_img+「x1.0」倍速胶囊 | ↺ | play_scale_img+「默认」比例胶囊 | play_player_img（**播放器切换**） | play_ijk（**硬解码/软解码**） | 3 枚图标钮（推断=**字幕**/♪音轨/⏱跳过提醒，位 1391/1526/1661） | 分隔线 | play_time_reset | play_time_start「00:00」（**跳过片头，可编辑**） | play_time_end「00:00」（**跳过片尾，可编辑**） | subtitle_view 全屏字幕层。
- 右侧大时钟「06:35:52」+「影片剩余 42:32 / 影片结束 05:18:24」（我方已有同款）。
- 播放中右半屏叠显详情信息（源/年份/…/按钮行/选集 tabs）——底层 DetailActivity 残留同屏，TVBox 自身瑕疵，不建议复刻。
- MENU 键：全屏无面板响应（tv_menu 实录为详情页 MENU）。

### 2.5 搜索页（tv_search / tv_hot）
- 顶 tab：**[全局搜索] [热门搜索]** 两入口；输入框右侧**筛选漏斗钮**（按源/类型收窄）。
- 按钮组：[搜索] [清空] [远程搜索] [删除]；36 键矩阵键盘；右侧搜索历史列+右上清空图标。

### 2.6 历史页（tv_hist）
- 海报卡墙：源前缀「影视|电影天堂」+「更新 20241231」角标+片名；右上 2 图标（清空/设置类）。

### 2.7 设置页全集（tv_set1..5.xml，左分组+右详情双栏）
| 组 | 条目（实测值） |
|---|---|
| 顶部 | 配置地址 |
| 首页 | 数据源(>选择页)、**窗口预览**(开启)、**数据源显示**(开启)、**按钮位置**、**画面缩放**(默认)、**后台**(关闭) |
| 推荐 | 站点推荐、历史条数(100条)、**播放器**(IJK)、**播放器设置**、启动时进直播(关闭)、**广告过滤**(开启)、自动测速(关闭) |
| 系统 | **语言**(中文)、**主题**(奈飞)、**换张壁纸/重置壁纸**、**渲染方式**(TextureView)、**搜索展示**(缩略图)、**嗅探Webview**(系统自带)、**安全DNS**(关闭) |
| 底部 | **数据备份还原**、**重置**、**聚搜**(已关闭)、关于 |

- 数据源选择页（tv_set4）：「请选择数据源」+√当前项+长列表（[直连]/(切) 后缀）。
- 备份还原页（tv_set3/5）：立即备份 / 存储权限 / 点击下方数据还原。
- 存储空间页（tv_cfg，▦ 入口）：右上 [主页][?][删除]。

## 三、逐屏对比与不足清单

优先级按点播主用途红线排：P0=直接影响日常点播体验；P1=便利性/可玩性；P2=长尾或我方有等价物、仅需入口对齐。

### 3.1 首页 / 顶栏
| # | TVBox | LibreTVaz 现状 | 不足 | 优先级 |
|---|---|---|---|---|
| H1 | 标题 pill=数据源快切入口 | 有独立换源钮（功能等价） | 无实质缺口，标题区不可点属习惯差异 | P2 |
| H2 | 顶栏信号条=一键全网测速 | 测速在独立「连接·点播源测速」页（ProbeScreen） | 入口层级更深，遥控到不了快捷位；可在顶栏加一枚测速钮直达 | P1 |
| H3 | 顶栏 ▦ 存储空间页 | 无 | 缺缓存/占用可视化+清理入口（我方清理在设置「清理缓存」一行，无占用数字） | P2 |
| H4 | 时钟含「周二」星期 | 网络+时钟小钮 | 无星期，细微差异 | P2 |
| H5 | 功能行含「文件」入口 | 无 | 本地文件播放入口缺失（TV 装 APK 场景低频） | P2 |

## 四、我方已覆盖或有意等价处（防误判为差距）

- 测速体系：TVBox=「测速」钮+自动测速开关；我方=六项定稿（暖机剔除/两阶段/中位数/余量比/并行/网络指纹）+ProbeScreen 全量测速墙，覆盖面更强。
- 推送/遥控：TVBox=推送二维码；我方=RemoteServer+RemoteHub+远程搜索+扫码自动导入+服务器地址+网络代理，体系更完整，仅缺 D2 的页内入口。
- 焦点效果：红底 40%+白描边已与 TVBox 一致（走查截图比对）。
- 换源：TVBox 首页快切=数据源页；我方有换源钮+快搜弹框逐源同名命中，路径等价。

## 五、未走查项（原因）

- 「播放器设置」内部参数页：两次导航被高频焦点漂移打断（转译卡顿+自绘焦点 dump 不可见），且 IJK 参数对标价值取决于 C6 是否立项，暂缓。
- 直播页：本配置无直播源，按 OK 无响应（仅记录）。
- MENU 键全屏态：无面板（已记录，非差距）。

## 六、建议实施批次（如放可，按点播红线优先）

1. **批一（P0/P1 高频）**：D2 详情页推送入口（复用 RemoteServer）→ F1 倍速胶囊常显（需用户复核 7 钮裁决）→ C13 数据备份还原 → C1 窗口预览开关。

3. **批三（P2 长尾，随迭代顺带）**：F5 比例文案、L2 历史页清空、H3 存储空间页、C2/C3/C4/C9/C11/C14 设置补齐。
