# O1 续播+自动换线 / O2 直播 EPG / O3 追剧角标+历史页+无结果推荐（方案）

> 状态：方案待确认（2026-10-30）。立项依据见《2026-10-30-同类项目对比与差距评估.md》O1/O2/O3。本轮只动 debug-web，安卓仅记映射。

## 背景与目标
用户在同类对比后勾选 O1+O2+O3。三项都是「观影/追剧/直播」核心体验补齐，成本低、可独立 revert：
- **O1**：跨会话续播（现在刷新即丢进度）+ 播放失败自动试备用线路（现在只弹「请换线路」让人手动点）。
- **O2**：直播 EPG 节目单（现在 #colEpg 是占位文案）+ 上次频道恢复 + 频道收藏。
- **O3**：收藏追剧更新角标 + 独立历史管理页 + 搜索无结果时基于拼音给「试试搜『XX』?」推荐（衔接已上线的拼音链）。

## O1

### O1a 跨会话续播进度
**现状**：`openDetail`→`App.resume` 只服务「搜本作」跨源跳转会话内续播；`fongmi_hist` 只存 id/name/pic/si，不含进度。
**方案**：
- 新增 localStorage `fongmi_prog` = `{ "<id>|<si>": { ep, sec, dur, ts } }`（key 与 hist/detail 同构：视频 id + 源下标）。
- `openDetail.paint` 内给 `#player` 挂：`timeupdate`（5s 节流写 `{ep:curEp, sec:currentTime, duration}`）、`pause`（立即写）、`ended`（删除该 key）。线路/集切换时更新 curEp 归属。
- 恢复优先级：`App.resume`（跨源即时跳转）> `fongmi_prog`（跨会话）。命中 prog 且非「已看完」时：`startEp=prog.ep`，起播后 seek 到 `prog.sec`（≥5s 才 seek，`loadedmetadata`/`canplay` 时执行），toast「继续播放 第N集 MM:SS」。
- 选集按钮对有进度记录者加小红点 class（`.ep.on` 旁）。
- 清理：写 prog 时顺带 prune `ts` 超 30 天或 id 不在 hist/keep 的孤儿项；删历史/取消收藏不清（下次看还能续）。
**边界**：直播 `playChan` 不记进度。hls seek 在 `MANIFEST_PARSED` 后设置 `video.currentTime`。

### O1b 播放失败自动换备用线路
**现状**：`playInto` 的 `dead()` 只 `toast('该线路无法播放…')`，用户需手动点线路。
**方案**：
- `playInto(video, url, title, onDead)` 新增末参 `onDead?`：`dead()` 改为 `if (!onDead || !onDead()) toast(...)`——回调返回 true 表示外层已改播下一条线路。
- `openDetail.paint` 内实现 `nextLine()`：从 `d.episodes` 里取**未试过且非当前**、优先含流后缀（`isStreamLink`）的线路，设 `line=i; curEp 保持`，`draw()` 后播同集新线路，并把该 i 记入闭包 `tried=new Set([line])`；无可选返回 false → 回原 toast。手动点线路/选集时清空 `tried`。
- 重试上限 = 线路数（天然），单次失败只跳一条，避免抖动循环。直播不接（单 url）。
**兜底**：`FONGMI_AUTOLINE=0`？——沿用 localStorage 开关 `fongmi_autoline`（默认开），关掉则 onDead 恒 false = 现状 toast。

## O2 直播 EPG

### 数据与解析
- 订阅里 `SRC.live[i].epg` 已保留（fongmi.js:461/466）。XMLTV 可能是 `.gz`：优先 `DecompressionStream('gzip')`（Chrome/Edge 现成），无则按原文试解析，失败即降级（列显示占位）。
- **纯函数进 perf-core**（node 无 DOMParser，用正则扫描，格式可预测）：
  - `parseXmltv(text)` → `{ channels:{id:name}, progs:{id:[{t,s,e,title,desc}]}, byName:{normName:id} }`
    - channel：`<channel id="x">…<display-name>NAME</display-name>…</channel>` 取首个 display-name。
    - programme：`<programme start="YYYYMMDDHHmmSS +ZZZZ" stop=… channel="id">…<title>…</title><desc>…</desc>`；时间戳去掉非数字取 14 位转 `+Number` 比较（源多为本地时区，够用）。
    - `normName`：去空格、大写、去尾「高清/标清/超清」、CCTV 归一（`cctv1`↔`cctv-1`）。
  - `epgFor(index, chanName, dayStartNum)` → 该频道某天节目列表（按 name→id 匹配，无则按 name 直接命中 progs key）；`epgNow(list, nowNum)` 取当前进行中项。
- 测试放 §9（构造小段 XMLTV 字符串断言频道名匹配、按天过滤、当前命中、时间戳解析、无 DOM 依赖）。

### UI 接线
- `Live` 增 `{ epgIndex:null, epgLoaded:false }`。进入直播且当前源有 epg → `fetchEpg()`（SWR 内存+localStorage `fongmi_epg:{url}` 5min）。
- `#colEpg`（原占位列）改：选中频道时渲染当日节目列表，当前项高亮 + 「正在」标，项上显 `HH:MM 标题`；点击有 `desc` 的项展开简介（回看/时移依赖源，不做承诺，占位说明）。
- `#ltEpg` 顶栏：`现在 · 节目名 (HH:MM–HH:MM)`，每分钟 timer 刷新当前项。
- `playChan` 内：设该频道后触发 `drawEpgCol()`；`#lbLine` 区域可显示下一节目倒计时（小项）。

### 上次频道 + 频道收藏
- `fongmi_live_last = { srcIdx, url }`：`playChan` 写入；`loadLiveList` 完成后按 url 定位 i 恢复（否则回落频道 0）。
- `fongmi_live_fav = [{ name,url,group,srcIdx }]`：面板频道列表项长按/按钮收藏；`Live.groups` 前置合成「★收藏」分组（过滤 fav）。收藏上限 100。

## O3

### O3a 追剧更新角标
- 收藏项结构扩展：写入时记 `{ id, name, pic, si, eps: 当前线路 list.length, last: d.remarks||d.last||'', ts }`（`openDetail` 收藏按钮、`renderKeep` 兼容旧项缺字段）。
- 进 `renderKeep` 时后台批量（复用 `pMap` 并发 3 + `httpGet(ac=videolist&ids=id)` + `parseDetail`）拉最新 eps/last，与记录比对；有更新 → 该项 `updated:true`，卡片右上红点 + 首页「收藏」功能行 `N 部更新`。点击进详情后清 `updated`。
- 结果 SWR 缓存 `fongmi_keepchk:{id|si}` 30min，避免频繁进页打源。单源失败静默。
**成本控制**：仅收藏页触发检测（非全局轮询）；收藏上限 50，最坏 50 请求分批，可接受。

### O3b 独立历史页
- 首页「最近观看」行头加「全部 ▸」→ 新视图 `App.view='hist'` + `switchView` 分支 + `onEsc` 回 home。
- `renderHist`：grid 全部 `fongmi_hist`（现上限 20→放宽到 60，写 hist 时同步扩），每项 `cardHtml(...,{del:true,showSite:true})`；头部「清空全部」按钮（confirm）。点击项 `openDetail`（配合 O1a 自动续播）。
- 删除项时顺带删 `fongmi_prog` 对应 key。

### O3c 无结果推荐（拼音衔接）
- `drawCollectTab`：当「全部」Tab 且各源已返回完（`Collect.done >= 参与源数`）且 `items` 为空 →
  - 纯字母 kw：`PerfCore.truncateByQuery(kw, pinIndex.fuzzy(kw,30) ,3)` 或 `pinIndex.suggest(kw,1)[0]` 取核心词，渲染「试试搜『复仇者』?」chip（复用 `data-k`→`run` 重搜，设 `Collect.kw=core` 重跑）。
  - 非字母/无建议：维持「该 Tab 暂无数据」，但补一句「可换首字母简拼或换源重试」。
- 需要在 renderCollect 记录参与源数以判「全部返回完」：`Collect.total = sources.length`，`finally` 里 `done++` 已有，判 `done>=total` 触发一次空态重绘。

## 兜底与回退
- O1a/O1b/O2/O3a/O3b/O3c 各自独立 commit，异常单步 `git revert`。
- 运行时开关：`fongmi_autoline`（关 O1b）、`fongmi_resume`（关 O1a 读取）；EPG/追剧检测失败静默降级为现状（占位/无角标）。
- 数据键**只新增不改动旧键**（fongmi_prog / fongmi_live_last / fongmi_live_fav / fongmi_keepchk），旧版本读取忽略，无迁移成本。
- `fongmi_hist` 上限 20→60 属放宽，兼容。

## 验证
1. `node test/cache-inval.test.mjs` 全绿（含 §9 EPG 组）。
2. 续播：看某剧到第3集 05:20 → 刷新 → 进同一剧同一源 → 自动第3集并 seek~05:20，toast 提示；`fongmi_resume=0` 则从头。
3. 自动换线：选一条会 fatal 的线路 → 不弹「请换线路」而是自动切下一条流后缀线路播放；全失败才 toast。
4. EPG：导入带 epg 的直播订阅（或本地 mock XMLTV）→ 频道列表 + 右列节目单 + 顶栏「现在·节目」；换台跟随；刷新恢复上次频道；收藏台进 ★ 分组。无 epg 源 → 列显示占位不报错。
5. 追剧：收藏一部更新中的剧，模拟源新增一集 → 进收藏页该项出现红点 + 首页「收藏 N 部更新」，点击进详情消失。
6. 历史页：首页「最近观看·全部」→ 独立页可逐条删 + 清空；删项后续播记录同清。
7. 无结果：打一个各源都无的简拼（如 `zzqq`）但词库/截断有近似核心 → 聚合页空态给「试试搜『XX』?」chip，点击重搜。
