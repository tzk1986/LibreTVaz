## 0. 全局约束（继承，每个任务隐含）

- 点播（VOD）是主用途，禁改坏；每任务收尾含点播回归。默认路径行为不变，新能力全走新 state/新开关。
- 私有站单 JSON 绝不入 git；备份产物（含源配置）只在设备侧，不得作为测试样例入库。
- commit/push 逐次用户放行；打包 `LibreTVaz-debug-20261110<letter>.apk` 已放行。
- 纯逻辑 TDD 先行（先 RED 后 GREEN）；构建 `cd android && ./gradlew.bat :app:testDebugUnitTest :app:assembleDebug -q`。
- 验证只用 emulator-5554（pixel7_api36 2400×1080）；遥控按键序列+screencap 同一条 Bash 命令；行内控件等高同字号（40dp 动作行不破）；始终中文注释/回复。

  3. SavedWall：`PosterCard(..., siteLabel = if (store.showSourceName) s.vod.sourceName else null)`（收藏+历史两池同组件自动同步）。

- 验收：开/关两态逐墙截图（搜索/历史/收藏/资源口）；焦点描边不受影响；开关持久化重启保留。

### T-A2 S1 热搜种子榜（低风险）
- 走查实锤：SearchScreen 中列空输入=「热门搜索」（本池词库 top40，`VocabStore` 双池，冷启动显「词库建设中…」SearchScreen.kt:340）；web 蓝本无热搜实现（纯我方扩展）；TVBox 热榜为其内置固定/接口榜。
- 方案：
  1. 新建 `data/SeedHot.kt`：`object SeedHot { const val VER="hot1"; val LIST = listOf(40 条高频热门点播片名，中文，无外链无源名) }`。
  2. VocabStore 加 `seedIfNeeded(ver)`：闸门键 `KEY_HOT_SEED`（SettingsStore 新 key）版本不符时把 LIST 经既有 `addWords(names, zone=false)` 灌入点播池（zone 池不灌）；首启/升版各一次，用户删过的不回填（闸门记录同 builtinSeedVer 模式）。
  3. 空态文案不动（词库异常时仍兜底）。
- 纯函数单测：LIST size==40、无重复、无空白；升版幂等（seed 两次条数不翻倍——用内存 VocabStore 测试或纯合并函数断言）。
- 验收：清数据首启 → 搜索页空输入即见 40 词流；点词直搜命中正常。
- 回滚：单提交 revert（闸门键残留无害）。

### T-A4 C4 画面缩放全局档（低风险）

  3. DetailScreen：`zoomMode` 初始化自 pref；两工厂 resizeMode 初值走 `zoomResizeMode`；档位 2（拉伸）仅初始呈现，比例钮仍走 FIT↔ZOOM 二档循环（TVBox 同：钮只翻两态）。
  4. 本次不应用于直播 PlayerScreen（点播优先，注明）。
- 验收：设置三档→进详情页预览/全屏初始画面对照截图；比例钮行为不回归。

### T-A3 F1 全屏倍速胶囊+面板（中低）
- 走查实锤：全工程无 `setPlaybackSpeed/PlaybackParameters`（倍速 UI+逻辑均在 11-10 版式裁决撤净）；动作行 7 钮 :1374-1388（Row + `rowFoc` 左右移焦 + 自隐重锚机制 :1371 注释）；FsAct 支持文字钮+`active` 态（:145/:178）。
- 方案：
  1. state：`speedX: Float = 1f`；`applySpeed()`＝`player.playbackParameters = PlaybackParameters(speedX)`；全屏退出时复位 1.0（防误触残留；裁决记录 §8-R2）。
  2. 动作行加第 8 项文字胶囊 `FsAct(if(speedX==1f)"倍速" else "x"+fmtSpeed(speedX), active = speedX!=1f)`，位置：播放钮之后。行仍 40dp 高、横滚兜底（超宽可滑，符合等高规范）。
  3. 点胶囊→全屏中层弹倍速面板：居中列 chips [0.5/0.75/1.0/1.25/1.5/2.0/3.0]，当前值红底白描边（TvColors 焦点同款），OK 选中并应用+收面板；BACK/再点胶囊=关；面板打开期间暂停控件 5s 自隐（与 fsBar 计时联动，实现时找自隐 LaunchedEffect 挂 `panelOpen` 条件）。
  4. 换集/换线保留 speedX（TVBox 行为，自动换线链不重置）。
  5. TDD：纯函数 `fmtSpeed(x): String`（1→"1.0"、1.25→"1.25"、0.5→"0.5"）+ `SPEED_OPTIONS` 常量断言。
- 冲突记录：用户 2026-11-10「仅 7 钮」裁决**仅对倍速一项放权恢复**；跳过/循环/选集/重置仍不上 UI。
- 验收：遥控走焦至胶囊→面板→选 1.5→画面进度加速实测（进度差）、胶囊显 x1.5 红高亮；点播回归全套。
- 回滚：胶囊与面板独立 state，单提交 revert 即回 7 钮版。

### T-B1 C1 窗口预览开关（中风险）
- 走查实锤：详情页进入即 `render()` 起播链（:603「渲染（web paint 等价）：默认线→6h 快线复用→resume/prog 覆盖→起播+测速」）；动作行播放钮「预览停摆才显」（Ruling④ :1112）；窗 OK/点按=进全屏（:1004）。
- 方案：
  1. SettingsStore 加 `winPreview: Boolean`（key `win_preview`，默认 true）；设置「首页」组「窗口预览」行（对齐 TVBox 同名项）。
  2. 关时：进入详情**不调 render()**（延后），视频窗显海报+常驻播放钮；`Ruling④` 显钮条件改为 `预览停摆 || !store.winPreview`。
  3. 起播入口归一：点播放钮或窗 OK＝执行 `render()` 并进全屏（关预览时「先小窗播」这一步整体跳过）；render() 内部链（默认线选择/resume/prog/测速/自动换线/autoSrc）**一行不改**，仅调用时机后移——这是风险受控的关键。
  4. 测速墙、连播、失败换线在预览关时同样在首次播放触发后生效（逻辑起点仍是 render()，无分叉）。
- 验收：关预览后——进详情窗不自动播、无 Mbps 读数（adb 网络零流量抽查）；点播放→全屏正常起播、resume 续位、测速标签出、连播可用；开预览=现行为逐像素不变。点播回归重点项。
- 回滚：单提交 revert；若仅钮显条件出岔，可先只 revert UI 条件行。

### T-B2 C10 渲染方式（低中）
- 走查实锤：两处 `PlayerView(ctx)` 工厂（:1019、:1229）；media3 1.11.1；SurfaceView 打洞致 screencap 视频区为黑（既有现象，走查已见）。
- 方案：
  1. SettingsStore 加 `textureView: Boolean`（key `render_texture`，默认 false）；设置「系统」组「渲染方式」行（文案「SurfaceView / TextureView」，对齐 TVBox）。

  3. 生效时机：`key(store.textureView) { AndroidView(...) }` 重建视图，进页即生效无需重启。
  4. 范围仅点播预览窗+全屏；直播不动（注记）。
- 额外可测断言：TextureView 开 → `screencap` 截到视频画面（SurfaceView 态截到黑块）——天然验证生效。
- 验收：两档切换后播放/拖拽/全屏/硬软解切换无回归；截图证据存 tmp。

### T-C2 C13 数据备份还原（中高，独立）
- 走查实锤：TVBox=立即备份/存储权限/点数据还原；我方设置全在 SharedPreferences 六库：`libretvaz`（设置）、`libretvaz_sources`（点播/直播源+订阅 KEY_VOD/KEY_LIVE/KEY_SUBS）、`libretvaz_keep`、`libretvaz_hist`、`libretvaz_prog`、`libretvaz_live`（直播收藏/分组）。
- 方案：
  1. 纯函数模块 `data/Backup.kt`：`pack(prefsMap): String` / `unpack(json): Map<prefName, List<TypedEntry>>`；类型标签 s/b/i/l/f；未知类型跳过并计数；`{v:1, ts, app, prefs:{…}}`。单测：往返一致、坏 JSON 报错不崩、类型保真。
  2. SAF：设置页「底部组」新增两行「立即备份」「还原数据」；备份=`CreateDocument`（建议名 `libretvaz-backup-YYYYMMDD-HHmm.json`），IO 线程写入；还原=`OpenDocument` → 解析成功弹**确认对话框**（覆盖全部当前配置+立即重生效提示）→ 应用后 relaunch（`packageManager.getLaunchIntentForPackage` + `finish`）。

- 验收：备份→adb pull 校验 JSON 结构（六库齐全）；清 app 数据→还原→设置/源/收藏/历史/进度全恢复；坏文件提示不崩。
- 回滚：新增文件+设置行独立提交，revert 即净。

### T-C1 F2+C6 播放器引擎两档（最高风险，最后做）
- 走查实锤：`buildPlayer(context, live, hwDecode): ExoPlayer`（PlayerScreen.kt:55，OkHttp+LoadControl+VideoCache+软/硬 codec 选择）；DetailScreen `player` 以 ExoPlayer 持有（:347 `remember(hwDecode)` 重建、:744 `player as? ExoPlayer` 取 videoFormat）；硬软解翻转的「记位→重建→续位」模板在 :440-450。
- **评审裁决（先写死）**：引擎档=①ExoPlayer（默认，全现有链）②系统 MediaPlayer（Android 原生支持 HLS/MP4，解码兼容兜底，即 TVBox「系统」档的价值）。**IJK 不做**：+原生 so 体积（arm64≈3-6MB）、独立解码栈与 Media3 全链（测速/预取/VideoCache/字幕层）无法复用、收益被「Exo 软解+系统档」覆盖；TVBox 的「播放器设置」内部参数页随 IJK 一并**不做**。此二条若日后翻案须另行评审立项。
- 方案：
  1. SettingsStore 加 `playerEngine: Int`（key `player_engine`，0=Exo 默认，1=系统）；设置「推荐」组「播放器」行（两档循环）。
  2. DetailScreen 引擎分支：`engine==1` 时走新组件 `SysPlayer`（`android.media.MediaPlayer` 包装，~200 行内）：
     - `SurfaceView` 独立 AndroidView（不走 PlayerView）；prepareAsync/seekTo/pause/resume/release + setOnInfo(BUFFERING) + setOnError→ 复用现有 buffering/errText/换线链（错误回调语义对齐 Exo 路径现有处理）。
     - 进度：现有 1s tick 轮询 `currentPosition/duration`（fsClock 区已在轮询，接入同源）。
     - 倍速：`setPlaybackParams`（API23+；系统档倍速可能失真——面板不变，接受降级并注记）。
     - 码率：MediaPlayer 无 bitrate 回调 → 顶栏 Mbps **不伪造**，显示「—」或隐藏该读数（裁决 §8-R5）。
     - 硬软解钮在系统档置灰 off（MediaPlayer 无 codec 选择面），toast 说明。
  3. 全屏动作行加「Exo/系统」文字胶囊（FsAct，位置=硬软解钮后），点=翻转 `playerEngine`+记位重建（完全套用 :440-450 模板：hwResume 同款 engineResume 快照）。
  4. 风险隔离：引擎判断集中在「工厂选择」一处；engine=0 时所有新代码零执行路径——默认用户完全无感。
  5. TDD：SysPlayer 状态壳纯逻辑（允许的命令序列/置位规则）抽纯函数先测；其余为装机实测。
- 验收：系统档起播主流源 3 部（不同 CMS）+暂停/seek/换集/退出、失败换线在系统档的行为记录；Exo 档全套点播回归与改前逐屏一致。任一不过=回退本提交并回报。
- 回滚：独立提交（可只 revert 引擎胶囊，保留设置行或一并撤）。
