## P0 崩溃 / 红线 / 安全（第一批修）

1. **【静默换源·红线】siteIdx 两套坐标系并存**
   `ui/BrowseScreen.kt:114,898` 写 **池下标**（`vodPool()`=`vodSources().filterNot{isAdult}`，`data/SourceStore.kt:38`），而 `ui/ProbeScreen.kt:38`（注释明言"行下标即 siteIdx"=全量）、`data/SourceGuard.kt:58-71`（全量下标自动切源写回）、`data/Zone.kt:130`（按池数量钳位）混用。存在成人源时两坐标错位：首页所选源≠实际播放源、测速墙选源被守护切错。
   修复方向：全链路统一按 **sourceKey/URL 定位**，或统一定义 siteIdx=全量下标并让 Browse 页换算；配纯函数单测。

2. **【崩溃】源管理删除按下标 removeAt 越界**
   `ui/SourcesScreen.kt:207-231` 把渲染时行下标闭包捕获；`data/SourceStore.kt:69,73` `list.removeAt` 无边界校验；期间 SourceGuard/Zone 归池/导入可能已 `replaceVod` 缩表 → IndexOutOfBounds fatal。
   修复方向：按 URL 删除 + 越界防御。

3. **【安全·局域网】RemoteServer 无鉴权、无超时、可注入订阅**
   `data/RemoteServer.kt:90-133`：通配 bind 9978、单线程内联 handle、`readLine` 无 SO_TIMEOUT 无长度上限；`/send?m=sub&t=…` 无 token；`data/SettingsStore.kt:48-50` qrAuto **默认 true**；`ui/SourcesScreen.kt:107-113` 收到即自动导入不确认；`MainActivity.kt:123` 常驻启动、`stop()` 从未被调。同网段任意设备可远程换源池/强制跳搜索/半开连接 DoS 远程输入。
   修复方向：二维码带一次性 token 校验 + SO_TIMEOUT/行长上限 + sub 导入必过确认（或 qrAuto 默认关）+ 弹窗打开才起服务。

4. **【遥控锁死】退全屏不复位 locked**
   `ui/DetailScreen.kt:402-410` exitFs 复位 speed 不复位 `locked`；`:886` locked 时 fsKeyMod 吞全部按键（除 Back/Escape）；解锁钮只在全屏层（`:1429,1439`）且方向键被吞→焦点无法移到解锁钮。纯遥控用户误锁→退→再进全屏即无法解锁，只能杀进程。
   修复方向：enterFs/exitFs 强制 `locked=false`（或锁定态定义长按 OK 3s 解锁兜底）。

5. **【低版本必崩】minSdk=23 但使用 java.time 且无 core library desugaring**
   `android/app/build.gradle.kts:14`（minSdk 23，全仓无 desugar 配置）；`ui/BrowseScreen.kt:637` `java.time.LocalDate.now()`（组合期直调）。Android 6/7（API 23-25）打开年份筛选面板即 NoClassDefFoundError。N1S（Android 9+）不受影响，但与声明矛盾。
   修复方向：minSdk 升 26（若无 6/7 目标设备），或启用 desugaring，并开 lint NewApi 防再犯。

## APK 体积专项（debug 32.07MiB 实测解剖）

**结论：偏胖但胖得集中——dex 18.12MiB(56.5%) + ICU4J 数据 10.26MiB(32.0%) 占 88.5%；业务代码仅约 1.07MiB，图片/native/assets 合计<0.2MiB。不是功能多，是打包方式+一个可替换巨型依赖。**

占比实测（20261111b 包，unzip/apkanalyzer 聚合）：

| 段 | 压缩 MiB | 占比 |
|---|---:|---:|
| classes×10（未 minify） | 18.12 | 56.5% |
| com/ibm/icu/**（3968 文件） | 10.26 | 32.0% |
| 增量打包空洞（可回收） | 1.84 | 5.7% |
| resources.arsc（82 locale） | 0.73 | 2.3% |
| zip 结构/META-INF/res/lib/assets | 1.12 | 3.5% |

精简清单（按优先级）：

1. **P0 ICU4J 替换**（省 11.5~12MiB，debug/release 同收）：ICU 仅 `data/perf/PinIndex.kt` 拼音首字母在用。方案 A（稳）=离线预生成 27,584 个 CJK 首字母表（~15KB，结果逐字一致）；方案 B=平台 `java.text.Collator(SIMPLIFIED_CHINESE)`（锚点边界字可能与 CLDR76 有微差）。保留 testImplementation icu4j 跑单测。风险低，PinIndexTest+锚点字抽查回归。
2. **P0 release 构建流程**（再省 7.5~10MiB）：现 release `isMinifyEnabled=false` 且无签名（build.gradle.kts:20-25）——切 R8+shrinkResources+签名（可复用 debug keystore 保覆盖升级），预计 dex 7~9.5MiB。media3 AAR 自带 proguard 规则、无反射坑，但需全功能回归（点播/HLS/缓存/二维码/拼音）。
3. **P1 发版 clean 重建**（回收空洞 1.5~1.8MiB）：AGP 增量打包以旧包为基底留死字节（20261105q 空洞仅 0.23MiB 为证）。发版脚本 `clean :app:assembleDebug`。
4. **P2 localeFilters("zh","en")**（0.2~0.4MiB，AGP9 写法）；**删死依赖** `androidx.tv:tv-material`（全工程 0 引用，拖 icons 0.27MB）、`ui-tooling-preview`（无 @Preview）（0.4~0.6MiB debug 端）。
5. **P3 可选**：WorkManager→进程内协程清理（省 0.15~0.25）；zxing 换最小 QR 编码器（0.1~0.2）。
6. **不建议动**：ABI 拆分（4 ABI 真实负载仅 37KB，还保 x86 模拟器）、assets 源 JSON（3.4KB）、v1 签名（minSdk23 装 Android6 必需）。

**路线预期**：只做 clean ≈30.3MiB → +ICU 替换 debug ≈18~19MiB → 切 release(R8+locale+clean+ICU) ≈ **8~11MiB**（同功能精瘦水平）。
